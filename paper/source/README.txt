To build
Install a standard XeLaTeX distribution with Latin Modern and Noto Serif CJK SC fonts. Run sh build.sh from this directory. Outputs are manuscript.pdf, reproduction_guide.pdf, contribution_comparison.pdf. No Lean proof is run by this command.

Use the separately identified version-5 Lean source archive for formal reproduction. The manuscript and its guide describe the exact artifact and commands. This clean package contains explanatory sources, not the earlier informal checker bundle and not a substitute proof archive.

This is a new edition. Earlier Library manuscript/source items remain unchanged as prior versions. No publication, repository change, expert outreach or submission was performed in preparing these files.
